# benchsiDE Knowledgebase

benchsiDE is a bulk RNA-seq analysis application that runs entirely in a web browser. It computes normalization, differential expression, gene-set tests, module screens and cross-dataset comparisons locally, without sending data to a server. Each statistical routine is validated against its reference implementation.

This knowledgebase explains what each part of the application does, how it is computed, and how to interpret it. For task-oriented instructions, see the [User Guide](../docs/user-guide.md).
